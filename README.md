# Your Name — Portfolio

A small gaming-themed portfolio site: HTML, CSS, and a touch of JS. No build tools needed.

## Run it in a Codespace
1. Push these files to a GitHub repo.
2. On the repo page: **Code → Codespaces → Create codespace on main**.
3. In the Codespace, install the **Live Server** extension (Extensions tab → search "Live Server").
4. Right-click `index.html` → **Open with Live Server**. Codespaces will forward the port so you can preview it in the browser.

## Customize it
- **index.html** — swap in your real name, bio, skills, and projects.
- **style.css** — colors are set as CSS variables at the top (`--violet`, `--cyan`, `--amber`) if you want a different palette.
- Skill bars: change the `--pct` value (e.g. `--pct:80%`) on each `.bar-fill` in index.html.

## Deploy for free with GitHub Pages
1. Push your repo to GitHub (if not already).
2. Go to **Settings → Pages**.
3. Under "Build and deployment", choose **Deploy from a branch**, pick `main` and `/ (root)`.
4. Save — your site will be live at `https://yourusername.github.io/reponame` within a minute or two.
